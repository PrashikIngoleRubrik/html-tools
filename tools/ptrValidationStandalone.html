PTR / Replacement Framework Validation — Standalone

Verify that Quote Lines (before order conversion) and Order Items carry the fields & JSON the New Replacement / Refresh framework is supposed to populate. Runs entirely in your browser — paste SOQL results, get a report.

How to pull the data from your org (read this first)

This page does not connect to Salesforce. You run the SOQL below in your org, export the result as JSON, and paste it here. Any of these work:

  • Salesforce CLI: sf data query --query "<SOQL>" --json (copy the whole output — the page reads result.records).
  • Workbench → REST Explorer / SOQL Query: run the query and copy the JSON response (the page reads records).
  • Developer Console / any tool that gives you an array of records.

The page accepts a raw array [ ... ], a { records: [...] } object, or the CLI's { result: { records: [...] } } shape. Keep the relationship sub-objects (e.g. SBQQ__QuoteLine__r, Order, Product2) — SOQL returns them automatically.
